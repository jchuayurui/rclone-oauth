Privacy policy

rclone-oauth · effective 25 November 2026

rclone-oauth is a personal Google OAuth client. Its owner uses it with rclone to back up files to their own Google Drive (about the app). This policy says what happens to Google user data when the app is authorized.

Data the app accesses

With the owner's authorization, rclone uses the Google Drive API to:

  • list folders and files and read their names, sizes, dates and checksums;
  • upload, download, move and delete files.

It does this only in the authorizing account's own Drive, and only when the owner's commands or scheduled jobs ask for it. The app does not read Gmail, contacts, calendars or any other Google data.

How the data is used and stored

  • Drive data is used only to copy, check and restore the owner's own files.
  • The OAuth token is stored in rclone's configuration file on the owner's computer. The developer runs no server, so no token or file content is sent to one.
  • File contents move only between the owner's computer and the owner's Google Drive.

Sharing

No Google user data is sold, shared, transferred to third parties, or used for advertising, analytics or training machine-learning models. No person other than the owner reads it.

Google API Services User Data Policy

rclone-oauth's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting rclone's configuration file removes the stored token. Files in Google Drive stay under the account owner's control and can be deleted there.

This website

This site sets no cookies and runs no scripts or analytics. It is hosted on GitHub Pages; GitHub's own privacy statement covers its hosting logs.

Changes and contact

Changes are published on this page with a new effective date. Questions: open an issue at github.com/jchuayurui/rclone-oauth/issues.
