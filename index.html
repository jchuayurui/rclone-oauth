rclone-oauth

A personal Google OAuth client for rclone.

rclone-oauth is the Google sign-in identity of one person's own copy of rclone, the open-source file sync tool. Its owner uses it to back up files from their own computer to their own Google Drive, and to read those files back. It is not a service, it is not offered to the public, and it has no users besides its owner.

When the owner authorizes it, rclone uses the Google Drive API to list, upload, download, check and delete files in the owner's Drive, and only when the owner's own commands or scheduled jobs ask it to. The sign-in token stays in rclone's configuration file on the owner's computer. No server receives it, and no data goes anywhere except between that computer and that Drive.
